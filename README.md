# MTDA Capstone Project

Exploratory analysis of the SRC radar signal dataset for the MTDA Capstone project.

## Repository Structure

- `scripts/` - Python analysis scripts
- `figures/` - Generated analysis figures
- `data/` - SRC datasets (not stored in Git)
- `downloads/` - Original downloaded archives (not stored in Git)

## Dataset

SRC Dataset 1: radar signal I/Q data with corresponding JSON detection and label files.
